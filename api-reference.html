AVORA API Reference

AVORA 서비스의 주요 API 엔드포인트 안내 페이지입니다. 실제 연동 전 인증 방식, 허용 이메일 정책, 환경변수 설정을 먼저 확인하세요.

Base URL:https://influencer-content-generator.netlify.app
Content-Type:application/json
Auth:세션 쿠키 기반(웹) + 서버 환경변수 기반(API)

Auth

GET/api/auth/session

현재 로그인 세션 조회

POST/api/auth/email

이메일 기반 로그인

GET/api/auth/sso/providers

사용 가능한 SSO 제공자 조회

GET/api/auth/sso/[provider]

SSO 로그인 시작

Generation

POST/api/generate-content

캡션/해시태그 등 텍스트 생성

POST/api/generate-image

이미지 생성(Higgsfield)

POST/api/generate-video

영상 생성

POST/api/generate-profile

프로필 생성

POST/api/generate-casting-board

캐스팅 보드 생성

Instagram

GET/api/instagram/status

Instagram 연동 상태 조회

POST/api/instagram/publish

콘텐츠 즉시 게시

GET/api/instagram/scheduled

예약 게시 목록 조회

POST/api/instagram/scheduled

예약 게시 생성

DELETE/api/instagram/scheduled/[id]

예약 게시 취소

Marketing

GET/api/marketing/campaigns

캠페인 목록/요약 조회

POST/api/marketing/campaigns

캠페인 생성

PATCH/api/marketing/campaigns/[id]

캠페인 수정

POST/api/marketing/collect

인사이트 수집 트리거

Example Request

curl -X POST "https://influencer-content-generator.netlify.app/api/generate-content" \
-H "Content-Type: application/json" \
-d '{
"inputSentence": "여름 신제품 소개 게시물 작성",
"profile": { "name": "AVORA 브랜드 캐릭터" },
"contentSettings": { "format": "reels", "aspectRatio": "9:16" }
}'
