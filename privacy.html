개인정보처리방침

AVORA(이하 "회사")는 이용자의 개인정보를 중요시하며, 관련 법령을 준수합니다.

공고일자: 2026년 6월 7일

시행일자: 2026년 6월 7일

  • 1. 수집하는 개인정보의 항목

회원 가입/관리: 이메일 주소, 로그인 제공자 정보, 계정 식별 정보

소셜 계정 연동: Instagram, Threads, YouTube, TikTok 등 채널 식별자, 프로필 정보, API 접근 토큰(필요 권한 범위 내)

콘텐츠 생성/운영 데이터: 프롬프트, 업로드 미디어, 생성 결과물(텍스트/이미지/영상), 예약/게시 이력, 댓글·DM 자동화 로그

자동 수집 정보: 접속 로그, 쿠키, 접속 IP, 기기/브라우저 정보, 서비스 이용 기록

유료 서비스 이용 시: 구독 상태, 플랜, 결제 상태, 청구 이력(민감 결제정보는 PG사 처리)

  • 수집 방법: 회원가입, 서비스 이용, API 연동, 문의 접수, 이벤트 참여, 생성 로그 수집 도구
  • 2. 개인정보 이용 목적
  • 회원 식별, 인증 및 계정 보안 관리
  • AI 콘텐츠 생성, 자동화(예약/댓글/DM), 성과 분석 기능 제공
  • 문의 응대, 공지 전달, 오류 대응, 부정 사용 탐지
  • 서비스 품질 개선 및 이용 통계 분석
  • 이벤트/마케팅 안내(관련 법령 및 동의 범위 내)
  • 3. 보유 및 이용기간

회사는 개인정보 수집 및 이용 목적 달성 시 지체 없이 파기합니다. 단, 관련 법령 또는 내부 보안 정책에 따라 일정 기간 보관이 필요한 정보는 해당 기간 동안 안전하게 보관 후 삭제합니다. 주요 예시는 다음과 같습니다.

  • 계약/청약철회 기록: 5년
  • 대금결제 및 공급 기록: 5년
  • 소비자 불만/분쟁 처리 기록: 3년
  • 로그인 기록: 3개월
  • 4. 개인정보 파기절차 및 방법

목적 달성 후 내부 방침 및 법령에 따른 보관기간이 종료되면 지체 없이 파기합니다. 전자적 파일은 복구가 어려운 방식으로 삭제하며, 출력물은 분쇄/소각 등으로 파기합니다.

  • 5. 개인정보의 제3자 제공

회사는 원칙적으로 이용자 동의 없이 개인정보를 외부에 제공하지 않습니다. 다만 법령 근거가 있거나 수사기관의 적법한 요청이 있는 경우 등에는 예외가 적용될 수 있습니다.

  • 6. API 서비스 연동 고지

회사는 서비스 기능 제공을 위해 외부 API를 사용할 수 있습니다. 예: YouTube API, Meta API (Threads/Instagram), TikTok API 등.

연동 기능 사용 시 각 플랫폼의 이용약관과 정책이 함께 적용됩니다.

회원은 플랫폼 보안 설정에서 언제든지 연동 권한을 철회할 수 있습니다.

계정 연동 해제 또는 탈퇴 시 관련 토큰/데이터는 정책에 따라 삭제됩니다.

  • 7. 수집한 개인정보의 위탁 및 국외 이전

회사는 서비스 제공을 위해 클라우드, 결제, 분석, AI 모델 제공사 등에 개인정보 처리를 위탁할 수 있으며, 필요한 경우 국외 인프라를 통해 처리될 수 있습니다.

  • 예시 수탁사: 클라우드/호스팅, 결제대행사, AI 모델 제공사, 알림/메일 서비스사

국외 이전 시 관련 법령에 따른 보호조치(접근통제, 최소수집, 보관기간 관리)를 적용합니다.

  • 8. 자동화된 결정에 대한 정보
  • AI 기반 콘텐츠 자동 생성
  • 규칙 기반 DM/댓글 자동 응답
  • 설정된 스케줄 기반 자동 게시

이용자는 자동화 처리 결과에 대해 설명 요청 또는 인적 개입을 요청할 수 있습니다.

회사는 만 14세 미만 아동의 회원가입을 제한하며, 관련 법령에 따른 보호 조치를 준수합니다.

현재 회사는 가명정보를 별도로 처리하지 않습니다. 향후 처리 시 관련 법령에 따라 고지합니다.

  • 11. 이용자 및 법정대리인의 권리와 행사 방법

이용자는 개인정보 열람, 정정, 삭제, 처리정지를 요청할 수 있으며 회원탈퇴 또는 문의 채널을 통해 권리를 행사할 수 있습니다.

연동 API 권한은 각 플랫폼 설정에서 직접 해제할 수 있고, 회사 내 연동 해제 시 관련 접근 토큰은 정책에 따라 삭제됩니다.

회사는 맞춤형 서비스 제공 및 이용 통계 분석을 위해 쿠키를 사용할 수 있습니다. 이용자는 브라우저 설정으로 쿠키 허용/거부를 선택할 수 있습니다.
